In Web Performance (Core Web Vitals) 👉 LCP = Largest Contentful Paint It’s a metric used by Google to measure how fast the largest visible element (like an image, video, or text block) loads on the screen. It tells you how quickly users can see the main content. Good LCP: ≤ 2.5 seconds Needs improvement: 2.5 – 4 seconds Poor: > 4 second -->

FID = First Input Delay A Google metric that measures the time between when a user first interacts with a page (click, tap, key press) and when the browser responds. It’s about interactivity — how responsive the site feels. Good FID: ≤ 100 ms -->
